# Requirements trace

Spec §4, one row per requirement. **Decisions** point to [design.md](design.md); **Planned evidence** is the test (or inspection) that will prove it, named now so it gets written next to the feature, not at Gate 4. **Status** is filled at Gate 5 (PASS / FAIL / PARTIAL + link) and mirrored in `docs/atp-report.md`.

Method: T test · D demonstration · I inspection · A analysis. Prio: M must · S should · E extension (owner-approved, judged by ATP-E1..E4, never part of the spec's acceptance rule; [design.md §11](design.md#11-extensions-owner-approved-2026-11-14)).
**Rule (D-ENG-14):** anything we build ships with its test in the same commit, including code that serves no single requirement (simulator, migrations, health checks); CI fails under 80 % coverage (D-ENG-15).
Test locations: `tests/unit/` (pure functions), `tests/integration/` (in-process code against real Redis + Postgres + MinIO from the compose file; counted in coverage), `tests/system/` (container kill, restart and pause tests against the full `make up` stack, run in the CI e2e job), `e2e/` (Playwright, TypeScript), `perf/` (measurement scripts, raw CSV to `docs/perf/`). Wall-clock thresholds are recorded in CI and judged on the reference machine in the ATPs (D-ENG-06, A-R2R-8). Hooks and thresholds (`CRASH_AT`, `STOP_AT`, `HANG_AT`, `RECLAIM_IDLE_MS`, `STEAL_IDLE_MS`, `SIM_SEED`) are listed in D-ENG-16. Design review 2 renamed or replaced some tests; none was removed (D-ENG-14).

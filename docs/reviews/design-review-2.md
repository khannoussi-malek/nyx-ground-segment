# Design Review 2: Nyx Ground Segment (closure + fresh angles)

Independent second review of `docs/design.md` (Gate 2 draft, enhancement round 1 applied, file as of 20:14 incl. D-ENG-20), checked against the spec ("spec"), `docs/requirements.md` (20:14), `docs/assumptions.md`, `docs/reviews/design-review-1.md` (RV-xx), the simplification review (SR-xx), the alternatives review (ALT-x, A-F/B-F/C-F), `research/S1-gate2-spikes.md` and R3/R4/R8/R9/R11 where a claim depends on them. The reviewer did not write the design. A claim in the design counts as a claim, not as evidence; every row below quotes the text it rests on.

## 1. Verdict

**PASS WITH CONDITIONS.** The Gate 2 thin slice (sim → one worker → store → SSE table) can start now, provided compose gets `init: true` and a TCP readiness check for the database (R2-07, R2-16), because both sit inside the slice. Three MAJOR findings must be fixed in the design first: R2-01 before Gate 3 day 2 (ingest depth), R2-02 before Gate 3 day 3 (commanding), and R2-03 at the Gate 2 actuals review. R2-01 is a direct contradiction between crash-only (SR-01) and the error isolation that closed RV-06, RV-27 and B-F1. R2-02 means the server-side two-step for hazardous commands can be skipped with one request. R2-03: the "26.7 h, inside ~27 h" claim compares gates 2–5 against a total that includes Gate 1.
